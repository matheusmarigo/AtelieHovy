## Sobre o Projeto
Este projeto tem como objetivo criar uma **plataforma de divulgação de produtos e serviços para microempreendedores nacionais**, servindo de intermediário entre o microempreendedor (desenhistas, costureiros(as), editores(as) e outras produções) e cliente.
