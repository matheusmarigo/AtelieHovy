## Sobre o Projeto
Este projeto tem como objetivo criar uma **plataforma de divulgação de produtos e serviços para microempreendedores nacionais**, servindo de intermediário entre o microempreendedor (desenhistas, costureiros(as), editores(as) e outras produções) e o cliente. Permitindo assim que esses microempreendedores também consigam divulgar suas redes sociais, formas de contato e métodos de pagamento pagamento   

A plataforma busca possibilitar que esses pequenos empreendedores ganhem espaço no mercado sem ter que competir com grandes empresas ou produtos falsificados produzidos em massa
